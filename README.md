## 📚 เกี่ยวกับหลักสูตรนี้

หลักสูตรนี้ครอบคลุมการเขียนโปรแกรมด้วย **Perl** ตั้งแต่ระดับเริ่มต้นจนถึงระดับมืออาชีพ ครอบคลุมหัวข้อ:
- Perl Programming พื้นฐานถึงขั้นสูง
- CGI (Common Gateway Interface)
- Web Scripting ด้วย Perl
- การพัฒนา Web Application แบบ Old-School
- Database Integration
- Security และ Best Practices

## 🛠️ การติดตั้งและการเตรียมตัว

### สิ่งที่ต้องการ
- Perl 5.10 หรือสูงกว่า (แนะนำ 5.36+)
- Text Editor (VS Code, Vim, Emacs)
- Web Server (Apache, Nginx) สำหรับ CGI
- CPAN

### การติดตั้ง Perl
```bash
# macOS
brew install perl

# Ubuntu/Debian
sudo apt-get install perl

# Windows
# ดาวน์โหลด Strawberry Perl จาก strawberryperl.com
```
